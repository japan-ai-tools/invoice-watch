プライバシーポリシー(案)

この方針は案です。有料の提供やサーバーでの見張りを始める前に、提供者が内容を確かめて確定します。

1. いまの版で扱う情報

取引先の一覧と公表データは、利用者の端末のブラウザの中だけで処理し、提供者のサーバーにも第三者にも送りません。画面は外部への通信をしない設定(Content-Security-Policy の connect-src 'none')で配っています。

2. 端末に残るもの

次回の比較のため、直前の結果をこの端末のブラウザの保存領域(localStorage)に1件だけ残します。ブラウザのサイトデータを消すと消えます。共用の端末では、使い終わったら消してください。

3. 個人の情報

取引先に個人事業者がいる場合、その名前と登録番号は個人に関する情報です。利用者は、登録番号の確認という目的の範囲でだけ使い、他人に見せたり外に出したりしないでください。

4. アクセスの記録

画面を置くホスティング(予定: Cloudflare Pages)は、配信のために通常のアクセスの記録(IPアドレス・日時など)を残すことがあります。提供者はそれを利用者の特定や広告に使いません。

5. これから(毎日の見張り・知らせ)

サーバーで毎日見張る版を始めるときは、預かる情報(取引先の一覧・知らせ先のメールアドレス)、保存の期間、消し方をこのページに書き、利用者の同意を得てから始めます。

6. 問い合わせ

窓口は有料の提供を始めるときにここに書きます。いまは GitHub の Issue で受け付けます。
