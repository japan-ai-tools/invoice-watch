利用規約(無料版)

2026年11月12日 制定。この規約は、いま無料で配っている版に適用します。提供者: japan-ai-tools(GitHub の公開アカウント)。問い合わせ: GitHub の Issue

1. このサービス

取引先インボイス見張り(以下「本サービス」)は、利用者が入れた取引先の一覧と、利用者が入れた国税庁の公表データを、利用者の端末の中で照らし合わせ、登録の状態と名称の違いを表示する道具です。

2. 国税庁のデータについて

本サービスは国税庁の公式のものではありません。表示する内容は国税庁によって保証されたものではありません。ダウンロードデータを使うときの出典の表示は「出典：国税庁適格請求書発行事業者公表サイト（国税庁）（https://www.invoice-kohyo.nta.go.jp/download/index.html）をもとに、取引先の一覧と照らすため加工して作成」です。Web-API の結果を使うときは、Web-API機能利用規約 第6条の文言をそのまま表示します:「このサービスは、適格請求書発行事業者公表システムWeb-API機能を利用して取得した情報をもとに作成しているが、サービスの内容は国税庁によって保証されたものではない」

3. 使ってはいけない使い方

公表サイトの検索画面を機械で取ったデータを入れること、公表データを名簿の販売や広告など登録番号の確認と関係のない目的に使うこと、法令や国税庁の利用規約に反する使い方はできません。

4. 判定の限り

本サービスの表示は税務の助言ではありません。仕入税額控除の可否など大事な判断は、国税庁の公表サイトでの確認や、税理士への相談で確かめてください。入れたデータが古い・欠けている場合、正しく判定できません。個人事業者の氏名はダウンロードデータで空のため、名称は目で確かめてください。

5. 責任

本サービスの表示を使ったことで生じた損害について、提供者に故意または重大な過失がある場合を除き、提供者は責任を負いません(消費者契約法など法令で認められない範囲を除きます)。

この規約を変えるときは、このページで知らせます。有料の版は、この無料版の規約とは別に、始める前に規約と特定商取引法に基づく表記を掲げます。
