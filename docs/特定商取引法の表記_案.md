# 特定商取引法に基づく表記(案)

有料の版(月額)を始めるときに掲げる表記の案です。いまは無料の版だけなので、まだ掲げていません。【 】の所は、提供者が有料の版を始める前に決めて書きます。

| 項目 | 内容 |
|---|---|
| 販売事業者 | 【氏名または屋号】 |
| 運営責任者 | 【氏名】 |
| 所在地 | 【住所】(請求があれば遅滞なく開示する形にする場合はその旨) |
| 電話番号 | 【電話番号】(同上) |
| メールアドレス | 【問い合わせ用】 |
| 販売価格 | 月額980円(税込) |
| 商品代金以外の必要料金 | なし(通信料は利用者の負担) |
| 支払い方法 | 【決済の方法】 |
| 支払い時期 | 申し込み時と、以後毎月の同じ日(更新日) |
| 提供時期 | 支払いの確認後すぐ |
| 契約期間 | 1か月ごとの自動更新。期間の定めはなく、解約するまで毎月更新します |
| 解約の締め切り | 次の更新日の【前日の23時59分】までに解約の手続きを終えると、次の更新日から課金しません |
| 解約の手順 | 【画面の「解約」ボタン、または問い合わせ先への連絡】。手続きが終わったら、その旨を画面またはメールで知らせます |
| 返品・返金 | デジタルの役務のため、提供開始後の返金はしません。日割りの返金もしません【要確認】 |
| 不具合のときの対応 | こちらの不具合で使えない状態が続いた場合は、【その月の代金の返金 または 期間の延長】で対応します。連絡は問い合わせ先へ |
| 適格請求書(インボイス) | 【発行できる(登録番号 T…)/ 発行できない(免税事業者のため。価格は税込980円)】のどちらかを明記します |
| 動作環境 | 最近の Chrome・Edge・Safari・Firefox |

## 申し込みの最終確認の画面に出すこと
定期の申し込みは、最終確認の画面に「月額980円(税込)」「1か月ごとの自動更新」「解約の締め切りと手順」を、申し込みのボタンの近くに分かる大きさで出します。

確かめる出典: 消費者庁「特定商取引法ガイド」通信販売の広告表示 https://www.no-trouble.caa.go.jp/what/mailorder/ ・ 2022年6月施行の最終確認画面の表示義務(定期購入の表示)。
