# 特定商取引法に基づく表記(案)— 有料の版を始める前に所有者が埋める

いまは無料なので掲げない(有料の申し込みを受ける時に必要)。【 】は所有者が決めて書く。NEXUS は埋めない(個人の住所・電話を NEXUS が記録しないため)。

| 項目 | 内容 |
|---|---|
| 販売事業者 | 【氏名または屋号】 |
| 運営責任者 | 【氏名】 |
| 所在地 | 【住所】(請求があれば遅滞なく開示する形にする場合はその旨) |
| 電話番号 | 【電話番号】(同上) |
| メールアドレス | 【問い合わせ用】 |
| 販売価格 | 月額980円(税込)— SALES_PAGE.md の値。変えるときは根拠を書く |
| 商品代金以外の必要料金 | なし(通信料は利用者の負担) |
| 支払い方法 | 【Stripe または Lemon Squeezy のどちらか。所有者がアカウントを作ってから】 |
| 支払い時期 | 申し込み時と、以後毎月の同じ日 |
| 提供時期 | 支払いの確認後すぐ |
| 解約 | いつでも画面から。次の更新日から課金しない。日割りの返金はしない【要確認】 |
| 返品・返金 | デジタルの役務のため、提供開始後の返金は不可。ただし不具合で使えない場合は【対応】 |
| 動作環境 | 最近の Chrome・Edge・Safari・Firefox |

確かめる出典(所有者が読む): 消費者庁「特定商取引法ガイド」通信販売の広告表示 https://www.no-trouble.caa.go.jp/what/mailorder/ ・ 2022年6月施行の最終確認画面の表示義務(定期購入の表示)。
